# RecordNow

Native macOS screen recording, focused non-destructive editing, export, and
YouTube Live streaming.

This repository hosts public releases only — no source code. RecordNow's
source is developed in a private repository.

## Downloads

No signed, notarized build has been published yet. Release assets (a
`RecordNow-X.Y.Z.zip`, checksums, and eventually a Homebrew tap) will appear
here once the release pipeline is in place.
