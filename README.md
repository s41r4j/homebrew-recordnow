# Record Now

**Record naturally. Edit selectively.**

A native macOS recorder for creators who need 4K quality without inheriting
an entire video-editing suite.

Native macOS screen recording with selection-based speed, zoom, blur,
highlights, text, face cam, and up to 4K export.

## Features

| | |
|---|---|
| **Face cam, placed after recording** | Turn it on when recording, then move it, resize it, show it, or hide it later. The camera stays independent so the final composition remains editable. |
| **Selection-based speed control** | Slow down a key step, skip repetitive waiting, or accelerate setup sections. Apply it only where needed instead of managing an overbuilt timeline. |
| **Zoom and highlight** | Pull attention to a button, panel, terminal output, or cursor path with restrained, editable visual emphasis that feels deliberate, not flashy. |
| **Blur sensitive information** | Blur passwords, tokens, email addresses, personal details, or internal data by selecting the area and time range. Keep the edit local and non-destructive. |
| **Text overlays and simple transitions** | Add titles, labels, and callouts, then join moments together with restrained transitions that do not make the product feel gimmicky or over-designed. |
| **4K recording and export** | Built for original high quality on macOS, with native-feeling performance, local-first processing, and export options that preserve clarity. |

<br><br>

## Select once, decide what that moment needs

In most screen-recording tools, everything turns into manual editing.
Record Now treats selection as the core action: first choose the exact
moment or region, then apply the right transformation.

- **Speed**: Increase or reduce the pace of the selected range.
- **Zoom**: Magnify the area that should hold attention.
- **Blur**: Hide sensitive content only where it appears.
- **Highlight**: Guide the eye using cursor and region emphasis.
- **Text**: Place labels, titles, or callouts with timing control.
- **Face cam**: Show, hide, move, or resize the camera at that point.

<br><br>

## Workflow: Record → Select → Export

1. **Record**: Choose the inputs. Turn on screen capture, system audio,
   microphone, and face cam. Confirm quality settings and start recording
   in a native macOS flow.
2. **Select**: Mark a moment or an area. Choose the time range or visible
   region that needs treatment. The interface stays focused and only
   exposes relevant actions.
3. **Export**: Keep the result sharp. Preview the final composition, then
   export in a clean delivery format with support for original resolution
   and up to 4K output.

<br><br>

## Quality: high quality in, high quality out

The screen, camera, microphone, and system audio are treated as proper
source material. Edits remain non-destructive until export, which means
more flexibility, cleaner output, and a workflow that feels professional
without becoming bloated.

| | |
|---|---|
| **Platform** | Native macOS application built for a fast, local workflow. |
| **Capture** | Screen, system audio, microphone, and face cam recorded with source fidelity in mind. |
| **Editing model** | Selection-based actions for speed, zoom, blur, highlight, text overlays, transitions, and camera changes. |
| **Export** | Original resolution or up to 4K, with modern codecs such as H.264 and HEVC. |

**4K**: not as a buzzword, as an expectation. Record Now is designed to
preserve clarity while removing the repetitive editing work that normally
slows tutorial and demo production down.
