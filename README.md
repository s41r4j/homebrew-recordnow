# Record Now

Record Now is a native macOS screen recorder with selection-based editing,
4K capture, blur tools, and a minimal professional workflow.

Native macOS screen recording with selection-based speed, zoom, blur,
highlights, text, face cam, and up to 4K export.

Website: [recordnow.s41r4j.in](https://recordnow.s41r4j.in/) (served from
`index.html` in this repo).

This repository hosts the public website and releases only — no source
code. Record Now's source is developed in a private repository.
