Feature set

Minimal on the surface, serious where it counts

The point is not to become a full editor. The point is to cover the repetitive, boring work that screen recordings always need: cleanly, professionally, and without visual clutter.

01

Face cam, placed after recording

Turn it on when recording, then move it, resize it, show it, or hide it later. The camera stays independent so the final composition remains editable.

02

Selection-based speed control

Slow down a key step, skip repetitive waiting, or accelerate setup sections. Apply it only where needed instead of managing an overbuilt timeline.

03

Zoom and highlight

Pull attention to a button, panel, terminal output, or cursor path with restrained, editable visual emphasis that feels deliberate, not flashy.

04

Blur sensitive information

Blur passwords, tokens, email addresses, personal details, or internal data by selecting the area and time range. Keep the edit local and non-destructive.

05

Text overlays and simple transitions

Add titles, labels, and callouts, then join moments together with restrained transitions that do not make the product feel gimmicky or over-designed.

06

4K recording and export

Built for original high quality on macOS, with native-feeling performance, local-first processing, and export options that preserve clarity.

The main interaction

Select once, decide what that moment needs

In most screen-recording tools, everything turns into manual editing. Record Now treats selection as the core action. First choose the exact moment or region. Then apply the right transformation.

ActionSpeedIncrease or reduce the pace of the selected range.
ActionZoomMagnify the area that should hold attention.
ActionBlurHide sensitive content only where it appears.
ActionHighlightGuide the eye using cursor and region emphasis.
ActionTextPlace labels, titles, or callouts with timing control.
ActionFace camShow, hide, move, or resize the camera at that point.
Workflow

Record → Select → Export

That is the product logic. Not twelve floating inspectors, not visual noise, not every possible editing control. Just the chain that screen-recording work actually wants.

01 / RECORD

Choose the inputs

Turn on screen capture, system audio, microphone, and face cam. Confirm quality settings and start recording in a native macOS flow.

02 / SELECT

Mark a moment or an area

Choose the time range or visible region that needs treatment. The interface stays focused and only exposes relevant actions.

03 / EXPORT

Keep the result sharp

Preview the final composition, then export in a clean delivery format with support for original resolution and up to 4K output.

Automation

A headless CLI for scripts and AI agents

recordnow-cli reads and writes the exact same project files the app does, so a script or an AI agent can inspect notes, apply edits, and export, all from the command line, through the same validated logic the app itself uses.

Install
brew install s41r4j/recordnow/recordnow-cli
Run as
recordnow <command> project.rnproject
Covers
Inspecting notes, applying and updating edits, exporting, and project settings, everything persisted in a project file.
Does not cover
Screen, camera, and microphone recording, live preview, and permission prompts stay in the GUI app (the Homebrew Cask), since macOS grants those only to a signed, launched application.
Quality

High quality in, high quality out

The screen, camera, microphone, and system audio are treated as proper source material. Edits remain non-destructive until export, which means more flexibility, cleaner output, and a workflow that feels professional without becoming bloated.
